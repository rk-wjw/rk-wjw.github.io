## 建议规划（分 3 个阶段）

### 阶段 1：先把首页信息结构搭起来（本次已完成模板）
目标：让访问者在 10 秒内知道“你是谁、做什么、如何联系你”。

建议模块顺序：
1. 顶部导航（首页 / 项目 / 关于 / 联系）
2. Hero 主视觉（你的名字 + 一句话定位 + CTA）
3. 个人简介（3~5 句）
4. 核心能力（技术栈/方向）
5. 代表项目（3 个卡片）
6. 联系方式（邮箱/社媒/GitHub）
7. 页脚（版权 + 更新时间）

### 阶段 2：内容真实化
目标：把占位文案替换为真实信息。

- 先完善“个人简介 + 代表项目 + 联系方式”。
- 每个项目补齐：背景、你的职责、技术、结果。
- 增加“可下载简历”或“微信/邮箱”作为转化入口。

### 阶段 3：视觉与性能优化
目标：让页面更专业，且加载更快。

- 引入统一颜色与字体系统。
- 增加响应式（移动端优先）。
- 压缩图片、延迟加载资源。
- 接入访问统计（如 Cloudflare Analytics / Plausible）。
